# 🪨 ГранитERP — CRM & ERP система для гранитной мастерской

Комплексная система учета, расчета смет, контроля производства и аналитики для мастерской памятников и обработки камня.

## 🚀 Быстрый запуск

### 1. Сервер (Backend API & База данных):
```bash
cd server
npm start
# API запустится на http://localhost:5000
```

### 2. Клиент (Frontend калькулятор и CRM):
```bash
cd client
npm run dev
# Откроется на http://localhost:5174
```

## 🛡️ Безопасность и защита от взлома
- **Закрытый доступ**: Вход строго по логину и зашифрованному паролю (**bcrypt** хэширование).
- **Защита от подбора паролей (Brute-Force Rate Limiter)**: Не более 10 попыток входа за 15 минут с одного IP.
- **JWT-токены**: Все запросы к данным защищены криптографической подписью токенов.
- **Разделение прав (Роли)**:
  - 👑 **Директор (Администратор)**: полный доступ, видит себестоимость закупки, чистую прибыль, маржинальность и может менять цены в справочнике.
  - 💼 **Приемщик заказов (Менеджер)**: оформляет заказы, рассчитывает клиентов, но **не видит закупочные цены и чистую прибыль**.

### 🔑 Тестовые доступы:
| Роль | Логин | Пароль | Доступ |
|---|---|---|---|
| Директор | `admin` | `admin123` | Полный доступ + себестоимость + редактор цен |
| Приемщик | `manager` | `manager123` | Оформление заказов, смета без себестоимости |

## 📋 Реализованный функционал (по ТЗ):

1. **🪨 Камни и материалы**:
   - Габбро-диабаз (Карелия, черный)
   - Дымовский (серый / буро-коричневый)
   - Мансуровский (светло-серый)
   - Мрамор Коелга (белый)
   - Сюскюянсаари (красный гранит)
   - Специфические коэффициенты наценки и закупочные цены на каждый камень.

2. **🗿 Стелы, тумбы и цветники**:
   - Стелы: прямые, волны, купола, резные кресты с размерами (ВхШхТ).
   - Подставки (тумбы) под стелы с габаритами.
   - Цветники стандартные и удлиненные (комплекты балок).
   - Надгробные плиты (сплошные и половинчатые).

3. **🧱 Калькулятор площадки и плитки**:
   - Ввод размеров участка (длина $\times$ ширина).
   - Автоматический расчет точной площади в м².
   - **Авторасчет количества плитки** с учетом запаса (+10% на подрезку и швы).
   - Расчет стоимости материала плитки и работы по укладке.

4. **🎨 Художественные и резные работы**:
   - Портрет компьютерный (станочный).
   - Портрет ручной (художник-гравер).
   - Гравировка ФИО + даты, кресты, цветы, эпитафия по количеству знаков.
   - Вырез форм: волна, фаски, сложная художественная резка.
   - Установка памятника на швеллер/балки и заливка бетонной подушки.

5. **🏷️ Редактор цен и номенклатуры (Админка)**:
   - Возможность в любой момент добавлять новые размеры и позиции.
   - Изменение розничных и закупочных цен в 1 клик.

6. **📋 Журнал заказов и печать**:
   - Статусы: Новый ➔ В цеху ➔ Гравировка ➔ Готов на складе ➔ Установлен ➔ Сдан.
   - Учет предоплат и остатка долга клиента.
   - Кнопка быстрой печати накладной/договора.
